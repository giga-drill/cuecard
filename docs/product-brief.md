# iOS 悬浮提词器（暂名）

## 产品目标

以开源项目 CueCard 的 iOS 悬浮提词器为基线，做一个能悬浮在相机、短视频和直播 App 上方的提词器。

正式名称待定。

## 已确认的新增需求

### 1. 横竖屏布局

- 默认按手机竖屏使用，悬浮提词器为竖向布局。
- 手机横过来拍横版视频时，悬浮提词器也切换为横向布局。
- 切换方向时不能丢失当前阅读位置、播放/暂停状态和计时进度。

### 2. 语音跟读滚动

- 保留按固定速度自动滚动的基础模式。
- 增加语音跟读模式：根据用户实际说到的文稿位置推进文字。
- 用户停顿时停止推进，语速变化时平滑跟随。
- 口误、重复、跳句后应尽量重新找到正确位置，不能因为一个常见词突然跳到文稿末尾。

## 当前工程决策

- GitHub 仓库采用标准 fork 工作流：`origin` 是 `giga-drill/cuecard`，`upstream` 是 `thisisnsh/cuecard`，只从上游拉取更新，不向上游推送。
- 第一版采用本地优先、无账号模式。移除 Firebase、Google 登录、云端统计和 Crashlytics；文稿与设置继续保存在本机。
- 画中画使用 iOS 公开 API。App 不再通过非公开调用强制进入后台，用户启动画中画后自行切换到相机或录制 App。

## 本轮边界

本轮完成：创建个人 fork、建立 Git 上游关系、清理 iOS 基线依赖、修复本地开发环境、审计现有实现、评估复杂度和代码规模。

本轮不完成：正式产品命名、横竖屏和语音跟读功能代码、App Store 发布。
